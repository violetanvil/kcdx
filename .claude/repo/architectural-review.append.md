## Repo additions — architectural-review

- **Design anchor** — `docs/design.md` + `.claude/rules/cornerstones.md` (UX > Capability > Performance; the disassembler test / AP12). kcdx has NO design-doc amend ceremony — a divergence from `docs/design.md` is surfaced to the user, never silently differed. Run the disassembler test as a §2 review trigger on every author-facing input the change adds: a common-task hex/ABI/offset/register/instruction-length burden is AP12, a defect to flag at source. Cornerstones decide ties; a proposal weakening a cornerstone needs a TECHNICAL justification, never an effort one. **Cornerstone gate (§"Design decisions surface"):** every surfaced option set clears `.claude/rules/cornerstones.md` §"Surfaced options clear the cornerstones first" BEFORE presenting.

- **Categorical fact sources + order (§"Verification order" §1/§2)** — an ABI / hook-signature / offset / vtable-slot / serialization claim is verified by reading the function body OR the authoritative record, in this order: `data/db-export/` CSV rows → prior `_research/` dumps → predecessor sigs → cached Warhorse wiki → Ghidra / `abi_walker` (`.claude/rules/address-library.md`). NOT a live WebFetch of a game URL, NOT prologue-shape guessing, NOT training-data recall of a CryEngine layout. CryEngine / Win32 / MinHook behavior → WebFetch a primary doc. `docs/known-issues/` trails and `docs/design-gaps.md` are diagnostic hypothesis logs, never primary evidence for a `// SOURCE:`-style claim.

- **§2 domain checks (design-fit / system-integration)** — hook engine: a new hook installs through the `conflict_engine` (a `conflict_engine` footprint + the `g_applyOrder` rank), MinHook is the sole hooking mechanism, a byte-patch is length-preserving (AP4); no new mempatch work — all byte-rewrite / hook / trampoline / engine-fix ships through kcdx. Every feature ships a permanent `test-plugins/` regression plugin + a matrix row (`.claude/rules/test-suite.md`).

- **§3 domain hazards (logical correctness)** — dual-Lua sentinel / heap corruption: a kcdx-allocated GCObject embedding a kcdx-side sentinel pointer corrupts WHGame's heap (`.claude/rules/lua-bridge.md`, PROBE Q); the hazard is BIDIRECTIONAL (kcdx's GC freeing WHGame `.rdata` is the reverse). Trampoline-after-unhook (dangling trampoline). `IConsole::AddCommand` is vtable `[33]`, NOT `[32]` (the function-pointer overload; `[32]` is the script-string overload). Save/load: cosave path derivation, cold-vs-warm load asymmetry, a serialization field an older save lacks. Every failure branch logs in the structured KV format — `LOG_*_KV(...)` with `log::KV(...)` (bare `KV(...)` fails C3861) per `.claude/rules/logging.md`.

- **Anti-pattern table** — kcdx numbers AP1–AP18; the catalog lives in `.claude/rules/anti-patterns.md`. Cite the numbered row (e.g. `[AP3 hit — raw RVA instead of Address Library ID]`), do not duplicate the catalog. Key rows the review leans on: AP1/AP2/AP3 (offset/ABI/vtable invention without Address Library / Ghidra evidence), AP4 (hook outside the conflict engine), AP7 (feature without its test plugin), AP10 (theorizing a checkable unknown), AP12 (author hex/ABI burden), AP17 (close without a root-cause mechanism paragraph), AP18 (new seed-DB row without user approval).
